# Пример: данные локального хранилища

Содержит файл `UsersData.json` — пример структуры данных, которые `FileAdapter` сохраняет для пользователей.

Сам по себе пример не запускается — это файл данных.

## Структура файла

```json
{
    "<userId>": {
        "userId": "<userId>",
        "meta": "<JSON-строка с метаданными>",
        "data": "<JSON-строка с данными пользователя>",
        "platform": "<имя платформы>"
    }
}
```

- Ключ верхнего уровня — значение первичного ключа (`userId` пользователя на платформе).
- `meta` и `data` хранятся как JSON-строки: модель `UsersData` сериализует объекты при сохранении и парсит их при чтении.
- `platform` — строковый идентификатор платформы (`alisa`, `telegram`, `vk` и т.д.).

Чтобы использовать файл как стартовое состояние хранилища, скопируйте его в директорию, заданную полем `json` в конфигурации приложения (`bot.setAppConfig({ json: '...' })`), — именно там `FileAdapter` ищет `UsersData.json`.
