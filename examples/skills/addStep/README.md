# Пример: многошаговый диалог (`addStep`)

Показывает, как строить цепочки диалога через `bot.addStep()` и переходы между шагами с помощью `botController.thisIntentName`:

- команда `start_step` запускает первый шаг;
- `step_1` спрашивает подтверждение и ветвится по ответу (`Text.isSayTrue`);
- `step_exit` обрабатывает выход из диалога (`isEnd = true`);
- `step_2` завершает сценарий.

## Как запустить

Это демо использует интерактивный консольный режим `BotTest` и общую конфигурацию из `examples/config/`. Скопируйте файл в свой проект, подключите свои конфиги и запустите через `bot.test()`.
