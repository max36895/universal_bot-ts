# Пример: собственный адаптер базы данных

Показывает, как реализовать свой адаптер БД (`DBAdapter` в папке `dbConnect`), наследуясь от базового класса `BaseDbAdapter`, и подключить его через `bot.use(new DBAdapter())`.

В примере используется только `AlisaAdapter` в качестве платформы. Руководство по созданию DB-адаптера — в `src/docs/adapter/dbAdapter.md`.

## Как запустить

Из папки `examples`:

```bash
npm install
npm run build
npm run user-db
```

Это демо использует интерактивный консольный режим `BotTest` и общую конфигурацию из `examples/config/`. Чтобы перенести пример в свой проект, скопируйте его файлы и запустите через `bot.test()`.
