# Пример: игра «Математика» на командах (`addCommand`)

Та же игра на сложение и вычитание, что и в примере `game`, но вся логика описана прямо в файле через `bot.addCommand()` — без отдельного класса-контроллера. Хорошо показывает, как строить сценарии командами и использовать `userData` для хранения текущего примера.

## Как запустить

Из папки `examples`:

```bash
npm install
npm run build
npm run game-in-command
```

Это демо использует интерактивный консольный режим `BotTest`: после запуска вводите команды прямо в терминале. Чтобы перенести пример в свой проект, скопируйте файл, подключите свои конфиги и запустите через `bot.test()` (разработка) или `bot.start()` (продакшн).
