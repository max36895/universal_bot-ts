# Пример: авторизация пользователя

Показывает сценарий с проверкой прав доступа: логика вынесена в `AuthController`, а параметры авторизации задаются в `examples/config/skillAuthParam.ts`.

Демо запускается в консольном режиме `BotTest` с выводом ответа, хранилища и времени обработки (`isShowResult`, `isShowStorage`, `isShowTime`).

## Как запустить

Из папки `examples`:

```bash
npm install
npm run build
npm run auth
```

Чтобы перенести пример в свой проект, скопируйте его файлы, подключите свои конфиги и запустите через `bot.test()`. Для продакшена замените `BotTest` на `Bot` и `bot.test()` на `bot.start()`.
