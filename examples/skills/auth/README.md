# Пример: авторизация пользователя

Демонстрирует флаг `isAuth` контроллера: по команде `auth` контроллер безусловно выставляет
`this.isAuth = true` (реальная проверка прав не выполняется — это демо флага). Полная авторизация
работает в Алисе при корректной настройке в кабинете разработчика навыка, а параметры задаются в
`examples/config/skillAuthParam.ts`.

Демо запускается в консольном режиме `BotTest` с выводом ответа, хранилища и времени обработки (`isShowResult`, `isShowStorage`, `isShowTime`).

## Как запустить

Из папки `examples`:

```bash
npm install
npm run build
npm run auth
```

Чтобы перенести пример в свой проект, скопируйте его файлы, подключите свои конфиги и запустите через `bot.test()`. Для продакшена замените `BotTest` на `Bot` и `bot.test()` на `bot.start()`.
