# Пример: кастомный HTTP-клиент

Показывает, как заменить встроенный `fetch` на собственный HTTP-клиент через `appContext.httpClient`. В примере каждый исходящий запрос логируется в консоль.

Это точка расширения для добавления retry-логики, тайм-аутов, tracing или моков в тестах. Подробнее — в `src/docs/http-client.md`.

## Как запустить

Это демо использует интерактивный консольный режим `BotTest` и общую конфигурацию из `examples/config/`. Скопируйте файл в свой проект, подключите свои конфиги и запустите через `bot.test()`.
