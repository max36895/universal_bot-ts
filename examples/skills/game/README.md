# Пример: игра «Математика» (продакшн-запуск)

Игра на сложение и вычитание с сохранением состояния между запросами. Логика вынесена в контроллер `GameController`, команды задаются интентами в `config/skillGameParam.ts`.

В отличие от остальных примеров, здесь используется не консольный режим `BotTest`, а полноценный запуск HTTP-сервера через `bot.start('localhost', 3000)` — так приложение работает в продакшене.

## Как запустить

Из папки `examples`:

```bash
npm install
npm run build
npm run game
```

Приложение поднимет HTTP-сервер на `localhost:3000`. Чтобы подключить к нему реальную платформу (например, Алису), нужен публичный URL: разместите приложение на сервере или пробросьте локальный порт через туннель, и укажите полученный адрес в консоли разработчика платформы.

Чтобы поиграть с ботом в консоли без сервера, закомментируйте `bot.start(...)` в конце `index.ts` и раскомментируйте блок над ним — бот запустится в интерактивном режиме `BotTest`.
