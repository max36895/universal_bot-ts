# Пример: стандартный навык

Минимальный шаблон полноценного навыка: подключение всех платформ, файловой базы данных, конфигурации, параметров и класса с логикой (`StandardController`).

Это отправная точка — с неё стоит начинать новый проект, если вы хотите писать логику в отдельном классе-контроллере, а не через `addCommand`.

## Как запустить

Из папки `examples`:

```bash
npm install
npm run build
npm run standard
```

Это демо использует интерактивный консольный режим `BotTest` и общую конфигурацию из `examples/config/`. Чтобы перенести пример в свой проект, скопируйте его файлы, подключите свои конфиги и запустите через `bot.test()`.
