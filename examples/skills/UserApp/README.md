# Пример: собственная платформа (кастомный адаптер)

Показывает, как добавить поддержку новой платформы через собственный адаптер (`UserAdapter` в папке `UserTemplate`). Адаптер реализует интерфейс `IPlatformAdapter` и подключается через `bot.use(new UserAdapter())`.

Это демонстрация расширяемости фреймворка: бизнес-логика (`UserAppController`) не меняется, меняется только адаптер. Руководство по созданию адаптера — в `src/docs/adapter/platformAdapter.md`.

## Как запустить

Это демо использует интерактивный консольный режим `BotTest` и общую конфигурацию из `examples/config/`. Скопируйте пример в свой проект и запустите через `bot.test()`.
