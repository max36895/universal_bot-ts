# Пример: регистрация команд (`addCommand`)

Показывает разные способы регистрации команд через `bot.addCommand()`:

- обычная команда со слотами-строками (`bigImage`, `list`, `save`, `exit`);
- команда с RegExp-слотом (`reg` — ловит любое число);
- fallback-команда `'*'` с флагом `isPattern`, которая эхом повторяет любой нераспознанный ввод.

Также демонстрирует работу с карточками (`botController.card.addImage`) и кнопками.

## Как запустить

Это демо использует интерактивный консольный режим `BotTest` и общую конфигурацию из `examples/config/`. Скопируйте файл в свой проект, подключите свои конфиги и запустите через `bot.test()`.
