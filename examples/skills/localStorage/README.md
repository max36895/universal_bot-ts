# Пример: локальное хранилище (localStorage)

Показывает работу с `userData` через локальное хранилище платформы (без внешнего DB-адаптера). Логика — в `LocalStorageController`, конфигурация — в `examples/config/skillStorageConfig.ts`.

Демо запускается в консольном режиме `BotTest` с выводом ответа, хранилища и времени обработки.

## Как запустить

Скопируйте пример в свой проект, подключите свои конфиги и запустите через `bot.test()`.
